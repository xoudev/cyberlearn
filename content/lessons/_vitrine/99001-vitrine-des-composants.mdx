Cette leçon n'apprend rien à personne : elle montre. Chaque composant que le guide de rédaction décrit y apparaît une fois, avec de vraies valeurs, rendu par le site exactement comme dans une leçon publiée. Elle sert à trois choses : vérifier qu'un composant marche encore après une modification, voir à quoi ressemble un composant avant de l'utiliser dans une leçon, et comparer l'aperçu de l'éditeur avec le rendu réel. Elle reste en brouillon, donc invisible des apprenants, et seul un administrateur peut l'ouvrir.

Les exemples viennent du guide de rédaction (`docs/LESSON_AUTHORING_GUIDE.md`) ou de leçons publiées. Quand un composant change, c'est ici qu'on le voit en premier.

## texte et mise en forme

Le texte d'une leçon est du Markdown ordinaire. On y écrit du **gras**, de l'*italique*, du `code en ligne`, et des listes :

- un élément ;
- un autre élément, avec un [lien vers le guide](https://github.com/xoudev/cyberlearn-revamp/blob/main/docs/LESSON_AUTHORING_GUIDE.md) ;
- un troisième, pour la forme.

Une liste numérotée garde l'ordre :

1. lire la consigne ;
2. essayer ;
3. comparer avec la correction.

Un tableau compare des valeurs :

| Commande | Rôle | Danger |
| --- | --- | --- |
| `cp` | copier | écrase sans prévenir |
| `mv` | déplacer ou renommer | écrase sans prévenir |
| `rm` | supprimer | pas de corbeille |

Une citation se détache du texte :

> Un fichier supprimé en ligne de commande est supprimé pour de bon.

Et un bloc de code s'affiche avec sa coloration, son numéro de langue et un bouton pour le copier :

```python
def saluer(nom: str) -> str:
    return f"Bonjour, {nom}."

print(saluer("monde"))
```

## un site en vrai PHP

Un vrai PHP tourne dans le navigateur. L'élève attaque la page, puis corrige son code ; le bouton de vérification rejoue les attaques sur sa version.

<PhpLab
  id="php-vitrine-xss"
  title="Le moteur de recherche du blog"
  task="Le blog rappelle au visiteur ce qu'il a cherché. Envoie une recherche piégée et regarde ce que le navigateur ferait de la page, puis corrige le code PHP pour qu'aucune recherche ne puisse plus y glisser du code."
  file="search.php"
  code={`<?php
$q = $_GET['q'] ?? '';
$articles = ['Introduction à PHP', 'Les tableaux en PHP', 'Sécuriser un formulaire'];
$trouves = array_filter($articles, fn ($titre) => $q === '' || stripos($titre, $q) !== false);
?>
<!doctype html>
<html lang="fr">
<head>
  <meta charset="utf-8">
  <title>Blog</title>
</head>
<body>
  <h1>Blog</h1>
  <form method="get" action="/search.php">
    <input name="q" value="<?php echo $q; ?>">
    <button>Rechercher</button>
  </form>
  <p>Résultats pour : <?php echo $q; ?></p>
  <ul>
    <?php foreach ($trouves as $titre) { echo "<li>$titre</li>"; } ?>
  </ul>
</body>
</html>
`}
