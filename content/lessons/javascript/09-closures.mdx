En JavaScript, les fonctions ne sont pas de simples blocs de code que l'on exécute : ce sont des valeurs de première classe. Cela signifie qu'une fonction peut être stockée dans une variable, rangée dans un tableau, transmise en argument à une autre fonction ou encore renvoyée comme résultat. Cette flexibilité est la fondation de deux concepts essentiels que nous allons explorer ici : les fonctions de rappel (les fameux callbacks) et les closures.

Maîtriser ces deux notions change radicalement la façon dont on écrit du code. Elles sont partout dans l'écosystème JavaScript : dans les méthodes de tableaux, dans la gestion des événements du navigateur, dans le code asynchrone et dans la plupart des bibliothèques modernes. Prenons le temps de bien les comprendre, étape par étape.

## Les fonctions comme valeurs

L'idée centrale est simple : une fonction est une valeur comme une autre. On peut donc l'assigner à une variable, exactement comme on assignerait un nombre ou une chaîne de caractères. Une fois rangée dans une variable, cette fonction peut être déplacée, copiée et passée ailleurs dans le programme.

<CodePlayground language="javascript" starterCode={`const saluer = function (nom) {
  return 'Bonjour ' + nom;
};

const direBonjour = saluer;

console.log(direBonjour('Alice'));
console.log(typeof saluer);`} />

Remarquez que `saluer` et `direBonjour` pointent vers la même fonction. Le `typeof` confirme que la valeur stockée est bien de type `function`. Puisqu'une fonction est une valeur, rien ne nous empêche de la donner en argument à une autre fonction.

## Les callbacks

Un callback est tout simplement une fonction passée en argument à une autre fonction, afin que cette dernière puisse l'appeler au bon moment. Le mot signifie littéralement rappel : on confie une fonction à quelqu'un en lui disant rappelle-moi quand ce sera prêt.

L'exemple le plus parlant est `setTimeout`, qui exécute le callback fourni après un certain délai. On peut aussi écrire nos propres fonctions qui acceptent un callback et l'appliquent.

<CodePlayground language="javascript" starterCode={`function appliquerDeuxFois(valeur, transformer) {
  return transformer(transformer(valeur));
}

const doubler = (n) => n * 2;

console.log(appliquerDeuxFois(5, doubler));

setTimeout(() => {
  console.log('Ce message arrive plus tard');
}, 0);`} />

Ici, `appliquerDeuxFois` ne sait pas à l'avance ce que fait `transformer` : elle se contente de l'appeler. C'est toute la puissance des callbacks, ils rendent une fonction générique et réutilisable.

<Callout type="info">
Les callbacks sont absolument omniprésents en JavaScript. Quand vous écrivez `tableau.map(...)`, `tableau.filter(...)` ou `element.addEventListener('click', ...)`, vous passez à chaque fois une fonction de rappel. Apprendre à les lire et à les écrire est donc indispensable.
</Callout>

## Les closures

Une closure (ou fermeture en français) est une fonction qui se souvient des variables de la portée dans laquelle elle a été créée, même après que cette portée a fini de s'exécuter. Autrement dit, la fonction emporte avec elle une partie de son environnement.

L'exemple classique est celui d'un compteur. Une fonction externe déclare une variable locale, puis renvoie une fonction interne qui modifie et lit cette variable. La variable reste accessible uniquement par la fonction interne.

<CodePlayground language="javascript" starterCode={`function creerCompteur() {
  let total = 0;
  return function () {
    total = total + 1;
    return total;
  };
}

const compteur = creerCompteur();

console.log(compteur());
console.log(compteur());
console.log(compteur());`} />

Chaque appel à `compteur()` incrémente la même variable `total`. Cette variable n'existe nulle part ailleurs : elle est capturée par la closure. On obtient ainsi un comportement qui se souvient de son passé entre deux appels.

<Callout type="info">
L'intérêt majeur des closures est de créer un état privé. La variable `total` est inaccessible depuis l'extérieur : impossible de la modifier directement ou de la corrompre par accident. C'est une forme d'encapsulation, très utile pour protéger des données sensibles dans votre code.
</Callout>

## Cas pratique

Les closures permettent de fabriquer des fonctions à la demande. On parle de fabrique de fonctions : une fonction qui renvoie d'autres fonctions, chacune préconfigurée avec ses propres valeurs capturées.

Construisons une fabrique de multiplicateurs. On lui donne un facteur, elle nous renvoie une fonction qui multiplie n'importe quel nombre par ce facteur.

<CodePlayground language="javascript" starterCode={`function creerMultiplicateur(facteur) {
  return (nombre) => nombre * facteur;
}

const tripler = creerMultiplicateur(3);
const parDix = creerMultiplicateur(10);

console.log(tripler(7));
console.log(parDix(7));`} />

Chaque fonction produite garde en mémoire son propre `facteur`. `tripler` se souvient de `3` et `parDix` se souvient de `10`, sans interférence entre les deux. C'est une closure en action, appliquée à un cas concret et réutilisable.

## Récapitulatif

- En JavaScript, les fonctions sont des valeurs de première classe : on peut les stocker, les passer en argument et les renvoyer.
- Un callback est une fonction passée à une autre fonction, qui l'appellera au moment voulu.
- Les callbacks sont partout : `map`, `filter`, `addEventListener`, `setTimeout`.
- Une closure est une fonction qui se souvient des variables de sa portée englobante.
- Les closures permettent de créer un état privé, encapsulé et protégé.
- Une fabrique de fonctions exploite les closures pour produire des fonctions préconfigurées.
