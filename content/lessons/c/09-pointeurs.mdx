Quand vous écrivez `int age = 30;`, le programme ne range pas ce 30 dans le vide. Il réserve une petite case dans la mémoire de l'ordinateur, il y inscrit le nombre, et il retient à quel endroit cette case se trouve. Cet endroit porte un numéro : une adresse. Tout ce qui suit dans cette leçon tient dans cette phrase. Une variable a une valeur, et elle a une adresse. Deux choses différentes.

Un pointeur, c'est juste une variable qui retient une adresse au lieu de retenir un nombre ordinaire. Rien de plus. Le mot fait peur, le mécanisme non.

Prenez l'image d'une adresse postale. La maison du 12 rue des Lilas contient des gens, des meubles, une vie. Sur une enveloppe, vous écrivez « 12 rue des Lilas ». L'enveloppe ne contient pas la maison. Elle dit seulement où la trouver. Avec cette indication, le facteur retrouve la maison et y dépose un colis. Un pointeur fait exactement ça : il ne contient pas la variable, il dit où elle est rangée, et avec cette indication le programme peut aller lire ou changer son contenu.

Gardez cette analogie sous la main. À chaque fois qu'une notion vous échappera, revenez à l'enveloppe et à la maison.

## l'adresse d'une variable

Pour demander « à quelle adresse cette variable est-elle rangée ? », on place l'opérateur `&` devant son nom. `&age` se lit « adresse de age ». Le résultat est un nombre, généralement affiché en hexadécimal, et pour l'imprimer avec `printf` on utilise le format `%p`.

<CodePlayground language="c" starterCode={`#include <stdio.h>

int main(void) {
    int age = 30;
    char lettre = 'A';

    printf("Valeur de age     : %d\\n", age);
    printf("Adresse de age    : %p\\n", (void *)&age);
    printf("Adresse de lettre : %p\\n", (void *)&lettre);

    return 0;
}`} />

Lancez ce programme plusieurs fois. Les adresses changent à chaque exécution, et c'est parfaitement normal : le système installe vos variables là où il y a de la place ce jour-là. Ne cherchez pas à retenir une adresse précise. Retenez la distinction. `age` répond à « quelle valeur ? », `&age` répond à « quel emplacement ? ».

## déclarer un pointeur

Pour ranger une adresse, il faut une variable taillée pour ça. On la déclare en mettant une étoile entre le type et le nom. `int *p;` se lit « p est un pointeur vers un int ». Autrement dit, p est prévu pour contenir l'adresse d'une case qui abrite un int.

Tant qu'on n'y a rien mis, p ne pointe vers rien d'utile. On lui donne une adresse, le plus souvent celle qu'on récupère avec `&`.

<CodePlayground language="c" starterCode={`#include <stdio.h>

int main(void) {
    int age = 30;
    int *p;          /* p peut contenir l'adresse d'un int */

    p = &age;        /* p contient maintenant l'adresse de age */

    printf("Valeur de age  : %d\\n", age);
    printf("Adresse de age : %p\\n", (void *)&age);
    printf("Contenu de p   : %p\\n", (void *)p);

    return 0;
}`} />

Regardez les deux dernières lignes. `&age` et `p` affichent la même adresse. C'est exactement ce qu'on voulait : p « pointe vers » age, comme l'enveloppe portait l'adresse de la maison. p ne contient pas le 30, il contient le chemin vers le 30.

## déréférencer avec l'étoile

Avoir l'adresse, c'est avoir l'enveloppe. Maintenant on veut entrer dans la maison. Cette opération s'appelle le déréférencement, et elle se note avec une étoile placée devant le pointeur au moment où on s'en sert. `p` désigne l'adresse, `*p` désigne la valeur rangée à cette adresse.

Et puisque `*p` est un autre nom pour age, on peut aussi écrire dedans pour changer age.

<CodePlayground language="c" starterCode={`#include <stdio.h>

int main(void) {
    int age = 30;
    int *p = &age;

    printf("Lecture via *p    : %d\\n", *p);   /* affiche 30 */

    *p = 42;                                   /* on ecrit a travers le pointeur */

    printf("age apres *p = 42 : %d\\n", age);   /* age vaut maintenant 42 */

    return 0;
}`} />

Modifier `*p`, c'est modifier age, parce que les deux pointent sur la même case mémoire. Vous n'avez pas touché à age directement, et pourtant sa valeur a changé. C'est toute la puissance, et tout le danger, des pointeurs.

Il reste un point qui embrouille tout le monde au début. L'étoile apparaît à deux moments qui n'ont rien à voir.

<Callout type="info">
Dans `int *p;` l'étoile fait partie de la déclaration : elle annonce « p est un pointeur ». Dans `*p = 42;` l'étoile est l'opération de déréférencement : elle dit « va à l'adresse contenue dans p et agis sur la valeur qui s'y trouve ». Même symbole, deux rôles. Au moment de l'utilisation, retenez aussi que p est l'adresse (l'enveloppe) et `*p` est la valeur (la maison). Ne les confondez jamais.
</Callout>

## pourquoi les pointeurs

Si tout ça ne servait qu'à écrire `*p = 42` au lieu de `age = 42`, personne n'en parlerait. L'intérêt apparaît dès qu'une fonction doit modifier une variable qui ne lui appartient pas.

En C, les arguments sont passés par valeur. La fonction reçoit une copie de ce que vous lui donnez. Elle peut tripoter cette copie autant qu'elle veut, l'original ne bouge pas. Pour qu'une fonction agisse vraiment sur votre variable, vous ne lui passez pas la variable, vous lui passez son adresse. La fonction déréférence alors ce pointeur pour atteindre l'original.

<CodePlayground language="c" starterCode={`#include <stdio.h>

void doubler(int *n) {
    *n = *n * 2;       /* modifie la variable d'origine */
}

int main(void) {
    int score = 21;

    printf("Avant : %d\\n", score);
    doubler(&score);   /* on passe l'adresse de score */
    printf("Apres : %d\\n", score);  /* 42 */

    return 0;
}`} />

Sans le `&`, la fonction `doubler` travaillerait sur une copie et `score` resterait à 21. C'est ce qu'on appelle le passage par adresse, et c'est la raison numéro un d'utiliser des pointeurs au quotidien.

Ce n'est pas la seule. Un pointeur permet aussi de parcourir un tableau case par case en avançant l'adresse, de manipuler des chaînes de caractères, et de bâtir des structures de données comme les listes chaînées, où chaque élément retient l'adresse du suivant. La mémoire réservée à la main avec `malloc` ne s'atteint d'ailleurs que par un pointeur. Difficile d'aller loin en C sans eux.

## le pointeur nul et les dangers

Un pointeur déclaré sans valeur ne pointe pas « vers rien ». Il pointe vers une adresse au hasard, celle qui traînait dans cette case mémoire. On appelle ça un pointeur sauvage. Le déréférencer revient à entrer par effraction dans une maison dont vous ignorez tout : le résultat est imprévisible, souvent un crash brutal, parfois une corruption silencieuse bien pire.

Pour dire proprement « ce pointeur ne pointe vers rien pour l'instant », le C fournit la valeur spéciale `NULL`. Vous initialisez vos pointeurs avec `NULL`, puis vous testez avant de déréférencer.

<CodePlayground language="c" starterCode={`#include <stdio.h>

int main(void) {
    int *p = NULL;     /* honnete : p ne pointe vers rien */

    if (p != NULL) {
        printf("%d\\n", *p);   /* on n'entre ici que si p est valide */
    } else {
        printf("p ne pointe vers rien, on ne dereference pas\\n");
    }

    return 0;
}`} />

<Callout type="warning">
Ne déréférencez jamais un pointeur non initialisé ni un pointeur valant `NULL`. Déréférencer `NULL` plante le programme à coup sûr, et déréférencer un pointeur sauvage est encore plus traître car le bug peut passer inaperçu un long moment. Deux réflexes à prendre tout de suite : initialiser chaque pointeur (avec `&variable` ou avec `NULL`), et vérifier qu'il n'est pas `NULL` avant tout `*p`.
</Callout>

Un dernier exercice pour ancrer le tout. La fonction `echange` ci-dessous intervertit les valeurs de deux variables en passant par leurs adresses. Lisez-la ligne à ligne et vérifiez que la sortie correspond bien à ce que vous attendez.

<CodePlayground language="c" starterCode={`#include <stdio.h>

void echange(int *a, int *b) {
    int temp = *a;   /* on sauve la valeur pointee par a */
    *a = *b;         /* a recoit la valeur pointee par b */
    *b = temp;       /* b recoit l'ancienne valeur de a */
}

int main(void) {
    int x = 1;
    int y = 9;

    printf("Avant : x = %d, y = %d\\n", x, y);
    echange(&x, &y);
    printf("Apres : x = %d, y = %d\\n", x, y);  /* x = 9, y = 1 */

    return 0;
}`} />

## à retenir

- Chaque variable occupe une case mémoire qui a une adresse ; un pointeur est une variable qui retient une adresse.
- `&v` donne l'adresse de v ; on l'affiche avec `%p`.
- On déclare un pointeur avec `type *nom;`, par exemple `int *p;`.
- `*p` déréférence : il accède à la valeur rangée à l'adresse contenue dans p, en lecture comme en écriture.
- L'étoile a deux rôles distincts : déclarer un pointeur dans `int *p;`, déréférencer dans `*p = 42;`.
- p est l'adresse, `*p` est la valeur. Ne jamais les mélanger.
- Le passage par adresse laisse une fonction modifier la variable d'origine au lieu d'une copie.
- Un pointeur non initialisé ou valant `NULL` ne se déréférence pas : initialisez toujours, testez avant `*p`.
