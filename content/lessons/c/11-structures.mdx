Une variable tient une seule valeur. Un tableau en tient plusieurs, mais toutes du même type. Le problème, c'est que les choses du monde réel ne sont presque jamais d'un seul type. Un point sur un écran a une abscisse et une ordonnée, deux entiers liés. Un produit a une référence, un prix, une quantité en stock. Un étudiant a un nom, un âge, une moyenne. Ces champs n'ont pas le même type et pourtant ils décrivent une seule et même chose.

Trimballer ces données dans des variables séparées marche au début, puis ça devient ingérable. Trois étudiants, c'est neuf variables sans lien entre elles. La structure répond à ça. Elle regroupe plusieurs champs de types différents sous un seul nom, comme une fiche cartonnée où chaque ligne est un renseignement. Une variable de ce type contient toute la fiche d'un coup.

## déclarer une structure

On définit une structure avec le mot-clé `struct`, un nom, puis la liste des champs entre accolades. Chaque champ ressemble à une déclaration de variable ordinaire : un type, un nom. Cette définition ne crée aucune donnée, elle décrit juste la forme. Ensuite on déclare une variable de ce type et on la remplit.

<CodePlayground language="c" starterCode={`{\`#include <stdio.h>

struct Point {
    int x;
    int y;
};

int main(void) {
    struct Point p;
    p.x = 3;
    p.y = 7;
    printf("Point: (%d, %d)\\\\n", p.x, p.y);
    return 0;
}\`}`} />

Notez le `struct Point p` pour déclarer la variable. Le mot `struct` fait partie du type, on ne peut pas l'omettre ici. On peut aussi initialiser une structure dès sa déclaration, dans l'ordre des champs.

<CodePlayground language="c" starterCode={`{\`#include <stdio.h>

struct Point {
    int x;
    int y;
};

int main(void) {
    struct Point depart = {0, 0};
    struct Point arrivee = {10, 5};
    printf("Depart en (%d, %d)\\\\n", depart.x, depart.y);
    printf("Arrivee en (%d, %d)\\\\n", arrivee.x, arrivee.y);
    return 0;
}\`}`} />

## accéder aux champs

L'opérateur point relie le nom de la variable à un champ. À gauche du point, la fiche ; à droite, la ligne qu'on veut. Ça marche dans les deux sens : en lecture pour récupérer la valeur, en écriture pour la changer. Chaque champ se comporte alors comme une variable normale de son type.

<CodePlayground language="c" starterCode={`{\`#include <stdio.h>

struct Produit {
    int reference;
    float prix;
    int stock;
};

int main(void) {
    struct Produit clavier;
    clavier.reference = 1042;
    clavier.prix = 29.90f;
    clavier.stock = 8;

    printf("Ref %d : %.2f euros, %d en stock\\\\n",
           clavier.reference, clavier.prix, clavier.stock);

    clavier.stock = clavier.stock - 1;
    printf("Apres une vente : %d en stock\\\\n", clavier.stock);
    return 0;
}\`}`} />

Chaque champ garde son propre type. `reference` est un entier, `prix` un flottant, et on les manipule comme tels. La structure ne fait que les ranger ensemble.

## typedef pour alléger

Écrire `struct Point` à chaque déclaration finit par peser. Le mot-clé `typedef` crée un alias : on donne un nom court au type, et on l'utilise ensuite sans répéter `struct`. C'est la forme la plus courante dans le code C que vous croiserez.

<CodePlayground language="c" starterCode={`{\`#include <stdio.h>

typedef struct {
    int x;
    int y;
} Point;

int main(void) {
    Point a = {1, 2};
    Point b = {4, 6};
    printf("a = (%d, %d)\\\\n", a.x, a.y);
    printf("b = (%d, %d)\\\\n", b.x, b.y);
    return 0;
}\`}`} />

Le nom placé juste après l'accolade fermante, ici `Point`, devient le nom du type. On déclare alors `Point a;` au lieu de `struct Point a;`. Le reste ne change pas : on accède toujours aux champs avec le point.

## struct et fonctions

Passer une structure à une fonction se fait de deux façons, et la différence compte.

Par valeur, la fonction reçoit une copie complète de la structure. Elle peut lire et modifier cette copie autant qu'elle veut, l'original chez l'appelant ne bouge pas. Pratique pour afficher ou calculer, mais si la structure est grosse, la copie coûte de la mémoire et du temps.

Par pointeur, on passe l'adresse de la structure avec `&`. La fonction ne copie rien, elle travaille directement sur l'original et peut donc le modifier pour de bon. Avec un pointeur, on n'accède plus aux champs avec le point mais avec la flèche `->`.

<CodePlayground language="c" starterCode={`{\`#include <stdio.h>

typedef struct {
    int x;
    int y;
} Point;

void afficher(Point p) {
    printf("(%d, %d)\\\\n", p.x, p.y);
}

void deplacer(Point *p, int dx, int dy) {
    p->x = p->x + dx;
    p->y = p->y + dy;
}

int main(void) {
    Point origine = {0, 0};

    printf("Avant : ");
    afficher(origine);

    deplacer(&origine, 5, 3);

    printf("Apres : ");
    afficher(origine);
    return 0;
}\`}`} />

`afficher` reçoit une copie et se contente de lire, donc le point suffit. `deplacer` reçoit un pointeur `Point *p` et modifie l'original parce qu'on lui a donné l'adresse avec `&origine`. À l'intérieur, `p->x` lit le champ `x` de la structure pointée.

<Callout type="info">
La flèche `->` est un raccourci. `p->x` veut dire exactement `(*p).x` : on déréférence le pointeur pour atteindre la structure, puis on lit son champ. La règle tient en une ligne : point sur une instance, flèche sur un pointeur. Si vous écrivez `p.x` sur un pointeur, ou `p->x` sur une instance directe, le compilateur refuse. C'est l'erreur la plus fréquente avec les structures au début.
</Callout>

## à quoi ça sert

Une structure sert d'abord à modéliser une entité du monde réel sans éparpiller ses données. Un personnage de jeu avec ses points de vie et sa position, une transaction avec son montant et sa date, une connexion réseau avec son adresse et son port : tout ce qui forme un ensemble cohérent devient une seule variable qu'on passe, qu'on stocke, qu'on range dans un tableau.

C'est aussi la brique de base des structures de données plus sérieuses. Une liste chaînée, un arbre, une file : tous reposent sur des structures qui contiennent leurs propres champs et des pointeurs vers d'autres structures du même type. Sans `struct`, rien de tout ça ne tient debout. Maîtriser le couple structure plus pointeur, c'est ouvrir la porte de la suite.

## à retenir

- Une structure regroupe plusieurs champs de types différents sous un seul nom, contrairement au tableau qui n'a qu'un seul type.
- On déclare une variable de structure avec `struct Nom variable;`, et on peut l'initialiser dans l'ordre des champs avec des accolades.
- L'opérateur point accède à un champ d'une instance : `p.x`, en lecture comme en écriture.
- `typedef` crée un alias pour écrire le nom du type sans répéter `struct`.
- Passée par valeur, une structure est copiée et l'original ne change pas. Passée par pointeur avec `&`, elle est modifiable.
- Sur un pointeur, on accède à un champ avec la flèche : `p->x`, qui est exactement `(*p).x`.
- Le piège classique : confondre le point et la flèche. Point sur une instance, flèche sur un pointeur.
