Jusqu'ici, vous avez manipulé des variables isolées et des tableaux qui ne contiennent qu'un seul type de donnée. Mais dans la vraie vie, les informations vont souvent par paquets. Un point sur un écran possède une coordonnée horizontale et une coordonnée verticale. Un étudiant possède un nom, un âge et une moyenne. Un produit possède une référence, un prix et une quantité en stock. Ces données sont liées entre elles, et il serait pénible de devoir les trimballer dans des variables séparées sans aucun lien logique.

C'est exactement le problème que résolvent les **structures**. Une structure permet de regrouper plusieurs données de types différents sous un seul nom, comme une fiche qui rassemble tous les renseignements d'une même entité. On parle de données **hétérogènes** parce que, contrairement à un tableau, une structure peut mélanger des entiers, des flottants, des chaînes de caractères, et même d'autres structures. Dans cette leçon, vous allez apprendre à définir une structure, à accéder à ses champs, à construire des tableaux de structures, et à passer une structure à une fonction.

## Définir une structure

On définit une structure avec le mot-clé `struct`, suivi d'un nom et d'une liste de **champs** entre accolades. Chaque champ est une variable classique avec son type. Une fois la structure définie, on peut créer des **instances**, c'est-à-dire des variables de ce nouveau type. Pour lire ou modifier un champ, on utilise l'**opérateur point** placé entre le nom de l'instance et le nom du champ.

<CodePlayground language="c" starterCode={`{\`#include <stdio.h>

struct Point {
    int x;
    int y;
};

int main(void) {
    struct Point p;
    p.x = 3;
    p.y = 7;
    printf("Point: (%d, %d)\\\\n", p.x, p.y);
    p.x = p.x + 10;
    printf("Apres deplacement: (%d, %d)\\\\n", p.x, p.y);
    return 0;
}\`}`} />

Remarquez que pour déclarer la variable, on écrit `struct Point p`. Le mot `struct` fait partie du type. C'est un peu verbeux, et c'est précisément ce que la section suivante va corriger.

## typedef - simplifier l'usage

Répéter `struct` à chaque déclaration devient vite fastidieux. Le mot-clé `typedef` crée un **alias** de type, ce qui permet d'écrire simplement le nom de la structure sans le préfixe `struct`. C'est la forme que vous rencontrerez le plus souvent dans le code C professionnel.

<CodePlayground language="c" starterCode={`{\`#include <stdio.h>

typedef struct {
    int x;
    int y;
} Point;

int main(void) {
    Point a;
    a.x = 1;
    a.y = 2;

    Point b;
    b.x = 4;
    b.y = 6;

    printf("a = (%d, %d)\\\\n", a.x, a.y);
    printf("b = (%d, %d)\\\\n", b.x, b.y);
    return 0;
}\`}`} />

<Callout type="info">
Avec `typedef struct { ... } Point;`, on peut désormais déclarer une variable avec `Point a;` au lieu de `struct Point a;`. L'alias rend le code plus lisible et plus proche d'un vrai type natif. Le nom placé juste après l'accolade fermante (ici `Point`) est le nom de l'alias.
</Callout>

## Tableaux de structures

Puisqu'une structure est un type comme un autre, on peut en faire des tableaux. C'est idéal pour représenter une collection d'entités semblables : un carnet de contacts, une liste d'étudiants, un inventaire. On accède à un élément du tableau par son indice, puis à un champ avec le point.

<CodePlayground language="c" starterCode={`{\`#include <stdio.h>

typedef struct {
    char nom[20];
    int age;
} Contact;

int main(void) {
    Contact carnet[3];

    carnet[0] = (Contact){"Alice", 30};
    carnet[1] = (Contact){"Bob", 25};
    carnet[2] = (Contact){"Chloe", 42};

    for (int i = 0; i < 3; i++) {
        printf("Contact %d: %s, %d ans\\\\n", i, carnet[i].nom, carnet[i].age);
    }
    return 0;
}\`}`} />

Ici `carnet[i].nom` se lit de gauche à droite : on prend l'élément d'indice `i` du tableau, puis on accède à son champ `nom`. L'initialisation `(Contact){"Alice", 30}` remplit les champs dans l'ordre de leur déclaration.

## Structures et fonctions

On peut passer une structure à une fonction de deux manières. **Par valeur**, la fonction reçoit une **copie** : modifier la copie n'affecte pas l'original. **Par pointeur**, la fonction reçoit l'adresse de la structure et peut donc la modifier réellement. Quand on dispose d'un pointeur vers une structure, on accède à un champ avec l'**opérateur flèche** au lieu du point.

<CodePlayground language="c" starterCode={`{\`#include <stdio.h>

typedef struct {
    int x;
    int y;
} Point;

void afficher(Point p) {
    printf("(%d, %d)\\\\n", p.x, p.y);
}

void deplacer(Point *p, int dx, int dy) {
    p->x = p->x + dx;
    p->y = p->y + dy;
}

int main(void) {
    Point origine;
    origine.x = 0;
    origine.y = 0;

    printf("Avant: ");
    afficher(origine);

    deplacer(&origine, 5, 3);

    printf("Apres: ");
    afficher(origine);
    return 0;
}\`}`} />

La fonction `afficher` reçoit une copie et se contente de lire. La fonction `deplacer` reçoit un pointeur `Point *p` et modifie l'original parce qu'on lui passe l'adresse avec `&origine`.

<Callout type="info">
Quand on a un pointeur vers une structure, l'opérateur flèche `->` permet d'accéder directement à un champ. Ainsi `p->x` est un raccourci équivalent à `(*p).x` : on déréférence le pointeur, puis on lit le champ. Retenez la règle simple : point avec une instance, flèche avec un pointeur.
</Callout>

## Récapitulatif

- Une **structure** (`struct`) regroupe plusieurs champs de types différents sous un seul nom : données **hétérogènes**.
- On accède à un champ d'une instance avec l'**opérateur point** : `p.x`.
- `typedef` crée un **alias** qui évite de répéter le mot `struct` à chaque déclaration.
- On peut construire des **tableaux de structures** pour gérer des collections d'entités, par exemple `carnet[i].nom`.
- Passée **par valeur**, une structure est **copiée** ; passée **par pointeur** (avec `&`), elle peut être modifiée.
- Avec un pointeur vers une structure, on accède à un champ avec l'**opérateur flèche** : `p->x`, équivalent à `(*p).x`.
